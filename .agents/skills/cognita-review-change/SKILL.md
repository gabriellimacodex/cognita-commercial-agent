# Revisar uma mudança

1. Aplicar primeiro `$cognita-engineering`.
2. Ler `../../../docs/engineering/workflows/code-review.md` e `../../../docs/engineering/checklists/reviewer.md`.
3. Ler objetivo, não objetivos, plano, ADRs e critérios de aceite.
4. Executar integralmente o workflow de code review e os checklists adicionais aplicáveis.
5. Verificar os gates de `../../../docs/engineering/workflows/pull-request.md` antes do veredito.
6. Usar `../../../docs/engineering/templates/review-report.md` quando o resultado precisar ser formalizado.
