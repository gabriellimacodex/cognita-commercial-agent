# Planejar uma mudança

1. Aplicar primeiro `$cognita-engineering`.
2. Ler `../../../docs/engineering/workflows/change-lifecycle.md`.
3. Ler `../../../docs/engineering/checklists/planning.md`.
4. Selecionar os Standards relacionados pelo índice `../../../docs/engineering/README.md`.
5. Consultar `../../../docs/adr/README.md` para decidir se ADR é obrigatória.
6. Produzir a evidência exigida pelo workflow usando `../../../docs/engineering/templates/change-plan.md`; usar `technical-spec.md` somente quando a complexidade justificar.
7. Apresentar o plano no gate definido pelo workflow.
