# Preparar uma Pull Request

1. Aplicar primeiro `$cognita-engineering`.
2. Ler `../../../docs/engineering/workflows/pull-request.md`.
3. Aplicar `../../../docs/engineering/checklists/self-review.md` ao diff completo.
4. Executar integralmente o workflow de Pull Request.
5. Preencher `../../../.github/PULL_REQUEST_TEMPLATE.md` com evidências específicas da mudança.
6. Usar o título definido por `../../../docs/engineering/conventions/commits.md` e reviewers derivados de `../../../.github/CODEOWNERS`.
