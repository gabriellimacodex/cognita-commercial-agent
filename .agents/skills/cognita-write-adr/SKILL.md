# Registrar uma decisão

1. Aplicar primeiro `$cognita-engineering`.
2. Ler `../../../docs/adr/README.md` e `../../../docs/engineering/workflows/adr-lifecycle.md`.
3. Consultar ADRs existentes relacionadas à decisão.
4. Executar integralmente o workflow de ADR.
5. Usar `../../../docs/engineering/templates/adr.md` sem criar outro formato.
6. Atualizar o índice canônico no mesmo conjunto da ADR.
