# Aplicar o CEF

1. Ler integralmente `../../../AGENTS.md`.
2. Ler integralmente `../../../docs/engineering/constitution.md`.
3. Usar `../../../docs/engineering/README.md` para selecionar Standards, Conventions, Workflows e Checklists aplicáveis.
4. Consultar `../../../docs/adr/README.md` e todas as ADRs aceitas relacionadas ao escopo.
5. Seguir integralmente `../../../docs/engineering/workflows/change-lifecycle.md`.
6. Encaminhar o trabalho para a Skill especializada:
   - planejamento: `$cognita-plan-change`;
   - decisão arquitetural: `$cognita-write-adr`;
   - implementação aprovada: `$cognita-implement-change`;
   - revisão: `$cognita-review-change`;
   - Pull Request: `$cognita-prepare-pr`.
7. Registrar somente evidências específicas da tarefa e referenciar as fontes canônicas.
