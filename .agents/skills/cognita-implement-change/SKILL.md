# Implementar uma mudança aprovada

1. Aplicar primeiro `$cognita-engineering`.
2. Ler `../../../docs/engineering/workflows/change-lifecycle.md` e confirmar seus gates de implementação.
3. Ler `../../../docs/engineering/checklists/implementation.md` e os Standards/Conventions selecionados pelo índice oficial.
4. Executar o plano aprovado sem substituir suas decisões.
5. Validar conforme o workflow e aplicar `../../../docs/engineering/checklists/self-review.md` ao diff completo.
6. Entregar evidências específicas para os critérios de aceite.
