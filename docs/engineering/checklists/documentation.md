# Checklist de Documentação

- [ ] Cada conceito possui uma fonte canônica.
- [ ] Conteúdo existente foi referenciado em vez de duplicado.
- [ ] Estado atual está separado de proposta futura.
- [ ] Termos seguem o glossário.
- [ ] Links relativos estão válidos.
- [ ] Status, versão e data foram incluídos quando necessários.
- [ ] Exemplos não contêm segredos ou dados reais.
- [ ] Comportamento alterado está refletido no mesmo PR.
- [ ] Documento obsoleto foi removido, substituído ou redirecionado.
- [ ] ADR, Standard, Convention, Workflow, Checklist e Template não foram confundidos.

Fonte normativa: `standards/documentation.md`.
