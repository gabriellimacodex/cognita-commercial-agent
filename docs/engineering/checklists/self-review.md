# Checklist de Self-review

- [ ] Diff completo foi lido contra a base correta.
- [ ] Cada arquivo pertence ao escopo declarado.
- [ ] Critérios de aceite possuem evidência.
- [ ] Nomes e limites expressam responsabilidade.
- [ ] Não há código, configuração ou documentação obsoleta.
- [ ] Casos de erro e concorrência relevantes foram verificados.
- [ ] Logs não expõem material sensível.
- [ ] Dependências novas estão justificadas e fixadas.
- [ ] Migrations aplicáveis foram revisadas separadamente.
- [ ] Testes são determinísticos e provam o risco.
- [ ] Comandos executados e resultados estão registrados.
- [ ] Testes não executados estão declarados.
- [ ] Links e referências documentais estão válidos.
- [ ] Rollback continua possível quando exigido.

Fonte operacional: `workflows/pull-request.md`.
