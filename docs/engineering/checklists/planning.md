# Checklist de Planejamento

- [ ] Objetivo e resultado esperado estão claros.
- [ ] Não objetivos e limites de escopo estão registrados.
- [ ] Estado atual foi inspecionado.
- [ ] Consumidores, dados e dependências afetados foram identificados.
- [ ] Risco foi classificado.
- [ ] ADR necessária foi criada ou explicitamente dispensada.
- [ ] Arquivos e áreas esperadas estão listados.
- [ ] Estratégia proposta é a menor que atende ao objetivo.
- [ ] Casos de falha e recuperação foram considerados.
- [ ] Estratégia de testes cobre os riscos principais.
- [ ] Rollout e rollback estão definidos quando aplicáveis.
- [ ] Critérios de aceite são objetivos e verificáveis.
- [ ] Decisões pendentes possuem responsável.
- [ ] Plano recebeu aprovação exigida pelo risco ou solicitante.

Fonte normativa: Constituição, Standards aplicáveis e `workflows/change-lifecycle.md`.
