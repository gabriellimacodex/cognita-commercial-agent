# Checklist de Implementação

- [ ] Existe autorização para implementar.
- [ ] Plano e ADRs aplicáveis estão aprovados.
- [ ] Escopo autorizado foi preservado.
- [ ] Mudanças preexistentes não relacionadas foram preservadas.
- [ ] Não foram criadas abstrações ou dependências hipotéticas.
- [ ] Entradas e saídas de fronteira são validadas.
- [ ] Erros, timeouts e shutdown foram tratados quando aplicáveis.
- [ ] Segurança e redaction foram consideradas.
- [ ] Testes foram criados ou atualizados com o comportamento.
- [ ] Documentação canônica afetada foi atualizada.
- [ ] Descobertas que alteram o plano foram escaladas.
- [ ] Artefatos temporários e código morto foram removidos.

Fonte normativa: Standards de arquitetura, código, testes, segurança e documentação.
