# Definition of Done

Uma entrega só está pronta quando:

- compila;
- lint passa;
- typecheck passa;
- testes passam;
- critérios de aceite foram cumpridos;
- documentação foi atualizada;
- logs foram adicionados;
- erros foram tratados;
- segurança foi revisada;
- não existem segredos no repositório;
- rollback é possível.
